# 多模态理解增强（astrbot_plugin_multimodal_enhance）

> 让 Bot 真正「看懂」图片、音频与视频。

为 AstrBot 补齐多模态理解能力：图片转述增强、语音/音频解析、音乐链接解析、视频抽帧理解，
并提供插件页面（总览 / 配置 / 插件日志 / 环境配置）可视化管理。

## 功能特性

- **带宽与并发**
  - 同时进行的媒体解析数量可配（默认 2），超出的消息自动排队，避免突发消息同时拉起多个处理任务；
  - 语音分块转写并发进行（按段号顺序拼接，不会打乱语义）；视频抽帧也改为并发抽取。

- **图片理解增强**：向图转文模型转述图片时，自动注入用户当前消息，让转述更贴合用户需求。
- **音频理解**
  - 语音、音频文件：自动转文本后与用户消息一起交给模型（即使 AstrBot 已开启原生「语音转文字」，插件也会独立完成语音解析，不受其开关影响）；若聊天主模型本身支持音频输入，则改为把音频作为附件直接发给模型（见下方「附件直传」）；
  - 音乐链接（网易云文本链接与分享卡片）：解析元数据 + 歌词 + 频谱数据（文本），无需转文本；若主模型支持音频输入，歌曲音频会作为附件直传，此时仍会附带歌名、歌手、专辑、时长与歌词（音频已在模型侧，故跳过频谱与深度分析）；
  - 可选「声纹包式深度分析」：BPM / 调性 / 音色四维 / 谐波占比 / 情绪等摘要。
- **视频理解**
  - 视频抽帧 + 逐帧画面描述 + 音轨解析（转文本或频谱）；若主模型支持图片输入，则抽帧改为图片附件直传，音轨按音频规则处理；
  - 支持直接发送的视频，以及回复/引用某条视频（@Bot 问「这是什么」也能解析）；
  - B站链接：自动获取标题 / 简介 / 发布时间，并按上限下载解析（默认 ≤10 分钟、≤100MB）；
  - 聊天主模型本身支持视频输入时，建议保持关闭。
- **插件页面**：总览（按 bot 分页）、配置（默认 + 每个 bot 分页的详细覆写，与 AstrBot 插件配置同一份文件）、插件日志（导出 + SSE 实时流，并同步转发到 AstrBot 官方 logger）、环境配置（一键安装全部依赖 / 清理临时文件）。
- **多 bot 适配**：全局默认配置 + 按单个 bot 覆写开关。

## 安装

在 AstrBot 插件市场搜索「多模态理解增强」，或使用仓库地址安装：

```text
https://github.com/baizi51676-source/astrbot_plugin_multimodal_enhance
```

环境要求：

| 组件 | 是否必需 | 说明 |
| ---- | -------- | ---- |
| AstrBot | 必需 | 4.27.0 及以上 |
| ffmpeg / ffprobe | 必需 | 抽帧、转码、频谱分析 |
| yt-dlp | 视频链接解析需要 | B站等站点下载 |
| numpy | 频谱分析需要 | 多数环境自带 |
| librosa / scipy / soundfile | 可选 | 音频「声纹包式深度分析」，可在插件页面一键安装 |

## 快速开始

1. 安装插件并重载；
2. 打开插件页面「配置」，按需开启图片 / 音频 / 视频功能；
3. 在「环境配置」中一键配置全部依赖（ffmpeg/ffprobe、yt-dlp、numpy/librosa/scipy/soundfile）；
4. 在群里发送图片、语音、音乐链接或视频链接即可。

## 配置说明

- 模型跟随 AstrBot 现有配置：
  - 图转文使用 AstrBot 的「图片描述」设置；
  - 语音转文本使用 AstrBot 的「STT」设置；
  - 未配置对应模型时，相应功能自动跳过，不影响其他能力。
- 常用参数：抽帧数量、抽帧宽度、视频时长/体积上限、频谱分段秒数、STT 单段上限、分析中提示词等；「分析中提示词」会作为指令交给模型，以当前会话人格生成提示消息，可自由修改。
- 「附件直传」与进阶参数：主模型支持音频/图片时，音频与抽帧改为附件直发（可分别关闭；未声明 modalities 时可选按支持处理）；另可调整同类媒体数量上限、是否总是输出频谱、长音频段数上限、深度分析秒数、逐帧描述并发数等。
- **多 bot 覆写**：在「多bot覆写」中按 JSON 列表配置，示例：

```json
[
  {
    "name": "示例规则",
    "bots": ["1234567890", "my_instance"],
    "overrides": {
      "video_enabled": true,
      "video_frames": 4
    }
  }
]
```

推荐直接在插件页面「配置 → Bot 分页」中可视化编辑覆写项；未覆写的项自动跟随默认配置。
未匹配任何条目的 bot 使用全局配置。

## 工作原理（简述）

- 图片：运行时包装 AstrBot 的图片转述流程，把用户当前消息按模板注入转述提示词；
- 音频/视频：消息到达后在后台解析（下载、转文本、抽帧描述、频谱计算），
  在调用模型前以「临时内容块」注入本轮请求——不污染历史、不影响提示词缓存。

## 常见问题

- **语音没有转文本？** 需在 AstrBot 中配置「语音转文本」模型；长音频会自动转为 16k 单声道并按「STT 单段上限」拆分转写（MiMo 等模型限制 10MB，建议 ≤7MB）；即使 AstrBot 已开启原生「语音转文字」（语音会被替换成文字），插件也会独立完成语音解析；默认已开启「接管语音转写」：插件启用时原生「语音转文字」将被截断，语音统一由插件处理（可在「基础」中关闭）；
- **图片增强没有生效？** 需配置「图片描述（图转文）」模型；
- **B站视频解析失败？** 插件自动走 B站官方 API 通道（不依赖 yt-dlp）；若 `view` 接口被数据中心 IP 风控（-412），会自动回退到搜索、分P列表与简介接口获取标题/UP主/时长/简介，再走 playurl 下载；超长/超大视频会按上限跳过下载；
- **磁盘占用？** 临时文件在任务结束后自动清理，也可在「环境配置」中手动清理。
- **长音频很慢或很吃内存？** 频谱分析默认只解码前 300 秒（可在「音频理解」的「频谱分析最长秒数」调整，0 = 不限制）；深度分析同样有「深度分析最长秒数」。长音频转写会自动拆分并并发处理。

## 隐私与安全

- 所有媒体解析在本机进行，不会上传到你未配置的第三方服务；
- 网络请求仅针对消息中出现的链接（音乐/视频平台）与依赖安装（pip 镜像）；
- 插件只下载 `http/https` 地址，并主动拒绝内网、回环、链路本地与云厂商元数据等地址；
  重定向会逐跳重新校验，跳转到内网同样会被拒绝（日志中会记一条「已拒绝不安全的媒体地址」）；
- 消息中的本地文件路径只接受位于插件数据目录或本次任务工作目录内的文件；
- 插件日志可在页面查看并导出，不含敏感凭据信息。
